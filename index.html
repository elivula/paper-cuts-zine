connect your github (one time only)

this is how the site knows it's you. connect once on each device you edit from, and editing stays on for that device.

  1. open github.com/settings/personal-access-tokens/new
  2. name it paper cuts, and set expiration to whatever you like
  3. repository access: only select repositories → paper-cuts-zine
  4. permissions → repository → contents → read and write
  5. click generate token, copy it, paste it below
